# Coffee Shop Sales Dashboard

## Project Overview

I created this Power BI dashboard to analyze coffee shop sales and understand how the business is performing.

The dashboard helps compare revenue, transactions, product categories, and store locations.

## Tools Used

- Power BI Desktop
- Microsoft Excel
- Maven Analytics Coffee Shop Sales Dataset

## What I Found

- Total sales were about $698.81K.
- Customers spent about $4.69 per transaction.
- Coffee brought in the most sales.
- Hell's Kitchen had the highest sales at $236,511.17.

## What I Learned

- Creating charts and dashboards in Power BI.
- Using DAX to calculate sales.
- Comparing sales across products and store locations.
- Using filters to explore data.
- Finding useful information from sales data.
